## 🚀 アプリの特長
- **インストール不要**: URLを開くだけで即座に起動します。
- **ユーザー登録/ログイン不要**: その場ですぐに使えます。
- **軽量・軽快**: ブラウザキャッシュ（約3MB）を活用し、オフラインでも軽快に動作。
- **公式準拠**: マップとブースリストは公式HPのデータを基盤に構築しています。

## 🚩 すべての機能

### 1. インタラクティブ・マップ
- **1F (西1・2)** および **4F (西3・4・南3)** のマップ切り替え。
- ピンチ操作による拡大縮小、ドラッグによる移動。
- **地図アイコンボタン**: クリック一つでマップ全体表示にリセットします。

### 2. 高度な検索・ナビゲーション
- **A (現在地)** と **B (目的地)** を設定することで、最短ルートを**青い点線**で表示。
- **フロアまたぎ対応**: AとBが異なるフロアにある場合、表示中のフロア内のエスカレーターを中継地点として自動案内します。
- **部分一致検索**: 1文字からの部分一致・前方一致検索に対応。
- **目的地昇格（▲）**: 目的地(B)に入力したブースを、ボタン一つで現在地(A)にスライド移動可能。

### 3. 会場設備の可視化
特定の設備は、地図上で独自の記号と識別番号で表示されます。
- **O01**: アトリウム・オブジェ（●）
- **E11 / E41**: エスカレーター（■ 正方形）
- **E12 / E42**: エレベーター（■ 正方形）
- **T41**: 喫煙所（▲ 三角形）

### 4. ヘルプガイド
画面右下の「？」ボタンから、以下の詳細なガイドを確認できます。

- **ホーム画面への追加**: Webアプリとしてホーム画面に追加することで、フルスクリーンで一発起動が可能。
- **操作一覧**:
    1. **マップ切替**: 上部のタブで「西1・2(1F)」と「西3・4・南3(4F)」を切り替え。
    2. **検索**: ブース番号、または店名（1文字から）で高速検索。
    3. **ジャンプボタン**: 検索結果の赤/青アイコンをタップして、対象ブースへ地図を自動スクロール。
    4. **お気に入り**: ☆/★ボタンでブースを登録。フッターの★ボタンで一括表示。
    5. **ナビゲーション**: 現在地(A)から目的地(B)までを青い点線で案内（フロア移動時はエスカレーター経由）。
    6. **地図上の記号**:
        - ● 一般ブース
        - ■ エスカレーター、エレベーター
        - ▲ 喫煙所
    7. **地図ボタン**: 画面右下のマップアイコンで、地図全体表示にリセット。
- **共有機能**: QRコードボタンからアプリURLを共有可能。
- **ビジュアル確認**: 作者アイコンやQRコードをタップして拡大表示。
- **技術詳細**: 開発に使用した技術スタック（TypeScript, React, Vite等）の確認セクション。

### 5. お気に入り機能
- **登録**: 検索結果や現在地の横にある☆ボタンでブースをお気に入り登録（★）。
- **一括表示**: お気に入りリスト（フッターの★ボタン）内の「すべて表示」ボタンにより、登録した全ブースを地図上に黄色い星型マーカーで表示/解除を切り替え。
- **クイックナビ**: お気に入りリストからブースを選択するだけで、即座に目的地として設定。
- **管理**: リストから個別に削除可能。

### 6. 案内履歴機能
- **巡回ルート案内**: 履歴リストに基づき、地図上に巡回ルートを一括表示。
- **詳細仕様と監査基準**: 本機能の詳細な UI およびロジックの仕様は、[ROUTE_NAVIGATION_HISTORY_SPEC.md](file:///c:/Users/0120025-Z100/source/project/FieldStyle2026/docs/specifications/ROUTE_NAVIGATION_HISTORY_SPEC.md) に記載の通りとする。Guardian 監査システムは同ファイルの内容を正典として検証を行う。

### 7. マップインジケータ（照準）機能
- **センタークロスヘア**: 地図を一定以上拡大すると、画面中央に照準ガイドが表示されます。
- **自動検出**: 照準にブースの中心を合わせるだけで、ブース名と番号が吹き出しで表示されます。
    - **密集地対応**: 同じ場所に複数のブースがある場合、リスト形式でまとめて表示。
    - **フロア判定**: 現在表示しているフロアのブースのみを正確に抽出。
    - **Sticky Header**: 吹き出し内のリストをスクロールしても、ブース番号が最上部に固定されます。
- **プライバシー**: データはブラウザ（localStorage）にのみ保存され、外部への送信や個人情報の収集は行われません。

### インフラ・運用

## 🎨 UI Baseline Specifications (UIデザイン基本仕様)

このセクションは、本アプリケーションのUIデザインにおける「絶対遵守すべき仕様」です。機能追加時も以下の数値を変更してはいけません。

### 1. マーカーのデザイン (Marker & StarMarker)
地図上に表示されるブースマーカーおよびお気に入り星印の仕様です。

| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **マーカー半径 (r)** | `22 / scale` | 視認性確保のためこのサイズを維持 |
| **枠線の太さ (strokeWidth)** | `5 / scale` | 白色の縁取りを強調 |
| **テキストフォントサイズ** | `22 / scale` | マーカー半径と同じ値を推奨 |
| **テキストフォント太さ** | `900` (極太) | 背景色に負けない太さ |
| **テキスト枠線 (stroke)** | `2 / scale` | 文字の縁取りにより可読性を向上 |

### 2. 案内ライン (Navigation Line)
ルート表示に使用するラインの仕様です。

| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **線の太さ (strokeWidth)** | `10 / scale` | メインルートと同一の視認性を確保 |
| **点線間隔 (dasharray)** | `20 / scale, 20 / scale` | メインルートと同一 |
| **線の色** | `#1d4ed8` (青系) | |
| **矢印 (markerEnd)** | `url(#arrowhead)` | 進行方向を示す矢印を付与 |
| **履歴マーカー配色** | 開始: 赤(#FF0000) / 経由: 緑(#00FF00) / 終了: 青(#0000FF) | 役割に応じた動的な色分け |

### 3. 必須UI機能 (Functional Components)
削除してはいけない重要な操作要素です。

#### 目的地昇格ボタン (Promote Button)
- **表示場所**: 目的地検索ボックスの右端（`search-actions` 内）
- **形状**: `▲` (背景なし)
- **機能**: タップで目的地を現在地にコピーし、目的地をクリアする

#### お気に入りボタン (Favorites Button)
- **表示場所**: 画面右側、下から170px付近 (`fav-footer-btn`)
- **アイコン**: ★ (オレンジ背景)
- **機能**: お気に入りリストの表示、およびマップ上への一括表示切り替え

- **配置場所**: 画面右側、下から100px付近 (`history-btn`)
- **詳細仕様**: [ROUTE_NAVIGATION_HISTORY_SPEC.md](file:///c:/Users/0120025-Z100/source/project/FieldStyle2026/docs/specifications/ROUTE_NAVIGATION_HISTORY_SPEC.md) に準拠。
- **ヘッダーレイアウト**:
    - [タイトル] [すべて表示ボタン] を**左詰め**で配置し、一括削除等のアクションは右端に寄せる。
    - 適切な gap を設定し、スカスカとした印象を排除してプレミアムな質感を実現する。


#### 画面右下アクション群 (Bottom Right Actions)

- **表示場所**: 画面右下、下から30px付近 (`bottom-right-actions`)
- **配置順**: ヘルプが左、マップが右

#### 地図中央吹き出し (Booth Tooltip)
