# 🧭 FieldStyle 2026 Navigator (PWA版)

> [!CAUTION]

> 1. ユーザーからの明示的な指示がない限り、AIは `git` コマンドや `vercel` コマンドを勝手に実行してはいけません。

FieldStyle Expo 2026 会場（AICHI SKY EXPO / 愛知国際展示場）向けの、スマートフォン最適化ブース検索・ナビゲーションアプリです。
**公開URL: [https://fieldstyle-nav.vercel.app](https://fieldstyle-nav.vercel.app)**

## 🚀 アプリの特長
- **インストール不要**: URLを開くだけで即座に起動します。
- **ユーザー登録/ログイン不要**: その場ですぐに使えます。
- **軽量・軽快**: ブラウザキャッシュを活用し、オフラインでも軽快に動作。
- **公式準拠**: マップとブースリストは公式HPのデータを基盤に構築しています（全641ブース 100%完全対応）。

## 🚩 すべての機能

### 1. インタラクティブ・マップ
- **屋内 (ホールC-F)**、**屋外エリア**、**DESTINATION AICHI** の3面マップ切り替え。
- ピンチ操作による拡大縮小、ドラッグによる移動。
- **地図アイコンボタン**: クリック一つでマップ全体表示にリセットします。

### 2. 高度な検索・ナビゲーション
- **A (現在地)** と **B (目的地)** を設定することで、最短ルートを**青い点線**で表示。
- **エリア跨ぎ自動中継**: 
  - **屋内 ↔ 屋外**: 各マップの出入口（赤⇔ゲートウェイ）を自動中継してルートを案内。
  - **DESTINATION AICHI**: 屋内中央（ホールD上部）のメインエリアへ自動誘導。
- **部分一致・あいまい検索**: 1文字からの部分一致・ブランド名（共同出展含む）検索に対応。
- **目的地昇格（▲）**: 目的地(B)に入力したブースを、ボタン一つで現在地(A)にスライド移動可能。

### 3. 会場中継地点・ゲートウェイの可視化
エリア跨ぎナビゲーションを支える主要な中継地点が登録されています。
- **GATEWAY-1**: 屋外エリアへの出入口（屋内側・ホールF 830上部 赤⇔）
- **GATEWAY-2**: 屋外エリア出入口（屋外側・901左下 赤⇔）
- **DESTINATION**: DESTINATION AICHI（屋内中央メイン展示エリア）

### 4. ヘルプガイド
画面右下の「？」ボタンから、以下の詳細なガイドを確認できます。
- **ホーム画面への追加**: Webアプリとしてホーム画面に追加することで、フルスクリーンで一発起動が可能。
- **操作一覧**:
    1. **マップ切替**: 上部のタブで「屋内」「屋外」「DESTINATION」を切り替え。
    2. **検索**: ブース番号や店名・ブランド名で素早く検索。
    3. **ジャンプボタン**: 検索窓横のボタンで対象に移動。
    4. **お気に入り**: ☆★ボタンで登録し、★ボタンで一括表示。
    5. **ナビゲーション**: 青点線でルートを案内（出入口ゲートウェイ経由）。
    6. **地図の操作**: ピンチ操作でズーム、ドラッグで移動。
    7. **地図リセット**: 右下の地図ボタンで全体を表示。
    8. **★ボタン**: お気に入り表示
- **共有機能**: QRコードボタンからアプリURLを共有可能。

### 5. お気に入り機能
- **登録**: 検索結果や現在地の横にある☆ボタンでブースをお気に入り登録（★）。
- **一括表示**: お気に入りリスト（フッターの★ボタン）内の「すべて表示」ボタンにより、登録した全ブースを地図上に黄色い星型マーカーで表示/解除を切り替え。
- **クイックナビ**: お気に入りリストからブースを選択するだけで、即座に目的地として設定。
- **管理**: リストから個別に削除可能。

### 6. 案内履歴機能
- **巡回ルート案内**: 履歴リストに基づき、地図上に巡回ルートを一括表示。
- **詳細仕様**: 本機能の詳細な UI およびロジックの仕様は、[ROUTE_NAVIGATION_HISTORY_SPEC.md](docs/specifications/ROUTE_NAVIGATION_HISTORY_SPEC.md) に記載の通りとする。

### 7. マップインジケータ（照準）機能
- **センタークロスヘア**: 地図を一定以上拡大すると、画面中央に照準ガイドが表示されます。
- **自動検出**: 照準にブースの中心を合わせるだけで、ブース名と番号が吹き出しで表示されます。
    - **密集地対応**: 同じ場所に複数のブースがある場合、リスト形式でまとめて表示。
    - **エリア判定**: 現在表示しているマップのブースのみを正確に抽出。
    - **Sticky Header**: 吹き出し内のリストをスクロールしても、ブース番号が最上部に固定されます。
- **プライバシー**: データはブラウザ（localStorage）にのみ保存され、外部への送信や個人情報の収集は行われません。

## 💻 使用技術・ツール

### 言語・フレームワーク
- **TypeScript**: 型安全なメイン言語
- **React (v19)**: UI 構築ライブラリ
- **Vite (v7)**: 高速ビルドツール
- **Python**: 座標検証・画像処理補助

### ライブラリ
- **PWA**: オフライン・インストール機能
- **Fuse.js**: 高速あいまい検索エンジン
- **react-quick-pinch-zoom**: 地図操作
- **Lucide React**: アイコン
- **OpenCV / EasyOCR**: マップ座標自動抽出システム（Map Maker 2）

### インフラ・運用
- **Vercel**: ホスティング、アナリティクス、自動デプロイ。
- **フィードバック**: 送信先は Vercel の環境変数 `FEEDBACK_URL`（値は `https://script.google.com/` の Web アプリ URL のみ）。ローカル確認は `.env.local` に同名で置く。未設定のときは「送信先が未設定です」と表示し、成功にはしない。
- **GitHub**: ソースコード管理。

## 🎨 UI Baseline Specifications (UIデザイン基本仕様)

このセクションは、本アプリケーションのUIデザインにおける「絶対遵守すべき仕様」です。機能追加時も以下の数値を変更してはいけません。

### 1. マーカーのデザイン (Marker & StarMarker)
| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **マーカー半径 (r)** | `22 / scale` | 視認性確保のためこのサイズを維持 |
| **枠線の太さ (strokeWidth)** | `5 / scale` | 白色の縁取りを強調 |
| **テキストフォントサイズ** | `22 / scale` | マーカー半径と同じ値を推奨 |
| **テキストフォント太さ** | `900` (極太) | 背景色に負けない太さ |
| **テキスト枠線 (stroke)** | `2 / scale` | 文字の縁取りにより可読性を向上 |

### 2. 案内ライン (Navigation Line)
| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **線の太さ (strokeWidth)** | `10 / scale` | メインルートと同一の視認性を確保 |
| **点線間隔 (dasharray)** | `20 / scale, 20 / scale` | メインルートと同一 |
| **線の色** | `#1d4ed8` (青系) | |
| **矢印 (markerEnd)** | `url(#arrowhead)` | 進行方向を示す矢印を付与 |
| **履歴マーカー配色** | 開始: 赤(#FF0000) / 経由: 緑(#00FF00) / 終了: 青(#0000FF) | 役割に応じた動的な色分け |

### 3. 必須UI機能 (Functional Components)
- **目的地昇格ボタン (Promote Button)**: 目的地検索ボックス右端の `▲` ボタン。
- **お気に入りボタン (Favorites Button)**: 画面右側、下から170px付近 (`fav-footer-btn`)。
- **案内履歴ボタン (History Button)**: 画面右側、下から100px付近 (`history-btn`)。
- **画面右下アクション群**: [？（ヘルプ）] [マップ（リセット）] の横並び配置。
