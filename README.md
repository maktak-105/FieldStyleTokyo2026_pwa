FieldStyle Japan 2026 会場（東京ビッグサイト）向けの、スマートフォン最適化ブース検索・ナビゲーションアプリです。
**公開URL: [https://fieldstyle-nav.vercel.app](https://fieldstyle-nav.vercel.app)**

## 🚀 アプリの特長
- **インストール不要**: URLを開くだけで即座に起動します。
- **ユーザー登録/ログイン不要**: その場ですぐに使えます。
- **軽量・軽快**: ブラウザキャッシュ（約3MB）を活用し、オフラインでも軽快に動作。
- **公式準拠**: マップとブースリストは公式HPのデータを基盤に構築しています。

## 🚩 主要な機能

### 1. インタラクティブ・マップ
- **1F (西1・2)** および **4F (西3・4・南3)** のマップ切り替え。
- ピンチ操作による拡大縮小、ドラッグによる移動。
- **地図アイコンボタン**: クリック一つでマップ全体表示にリセットします。

### 2. 高度な検索・ナビゲーション
- **A (現在地)** と **B (目的地)** を設定することで、最短ルートを**青い点線**で表示。
- **フロアまたぎ対応**: AとBが異なるフロアにある場合、表示中のフロア内のエスカレーターを中継地点として自動案内します。
- **部分一致検索**: 1文字からの部分一致・前方一致検索に対応。

### 3. 会場設備の可視化
特定の設備は、地図上で独自の記号と識別番号で表示されます。
- **O01**: アトリウム・オブジェ（●）
- **E11 / E41**: エスカレーター（■ 正方形）
- **E12 / E42**: エレベーター（■ 正方形）
- **T41**: 喫煙所（▲ 三角形）

### 4. ヘルプガイド
- 画面右下の「？」ボタンから、操作方法の簡易ガイドを確認可能。
- **共有用QRコード**: ガイド内のQRボタンから、アプリのURLを共有するためのQRコードを大きく表示できます。
- **作者プロフィール**: ガイド内の作者アイコンをタップすることで、画像を拡大表示できます。

### 5. お気に入り機能
- **登録**: 検索結果の横の☆ボタンでブースをお気に入り登録（★）。
- **一括表示**: フッターの★ボタンから、登録した全ブースを地図上に黄色い★マーカーで表示。
- **クイックナビ**: お気に入りリストから選択するだけで、即座に目的地として設定。新しく追加したものが上から表示されます。
### 6. マップインジケータ（照準）機能
- **センタークロスヘア**: 地図を300%（初期状態から3倍）以上拡大すると、画面中央に照準ガイドが表示されます。
- **自動検出**: 照準にブースの中心を合わせるだけで、ブース名と番号が吹き出しで表示されます。
    - **密集地対応**: 同じ場所に複数のブースがある場合、リスト形式でまとめて表示。
    - **フロア判定**: 現在表示しているフロアのブースのみを正確に抽出。
    - **Sticky Header**: 吹き出し内のリストをスクロールしても、ブース番号が最上部に固定されます。
- **プライバシー**: データはブラウザ（localStorage）にのみ保存され、外部への送信や個人情報の収集は行われません。

すべてのコマンドは、プロジェクトのルートフォルダ **`fieldstyle-nav-pwa`** で実行してください。

修正を GitHub に保存します。これにより Vercel へ自動デプロイされます。
```bash
git add .
git commit -m "修正内容を記入"
git push
```

### 3. 本番デプロイ (Vercel)
手動で即座に本番反映させたい場合、またはプロジェクトを再リンクする場合に使用します。
```bash
npx vercel --prod
```

## 🎨 UI Baseline Specifications (UIデザイン基本仕様)

このセクションは、本アプリケーションのUIデザインにおける「絶対遵守すべき仕様」です。機能追加時も以下の数値を変更してはいけません。

### 1. マーカーのデザイン (Marker & StarMarker)
地図上に表示されるブースマーカーおよびお気に入り星印の仕様です。

| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **マーカー半径 (r)** | `22 / scale` | 視認性確保のためこのサイズを維持 |
| **枠線の太さ (strokeWidth)** | `5 / scale` | 白色の縁取りを強調 |
| **テキストフォントサイズ** | `22 / scale` | マーカー半径と同じ値を推奨 |
| **テキストフォント太さ** | `900` (極太) | 背景色に負けない太さ |
| **テキスト枠線 (stroke)** | `2 / scale` | 文字の縁取りにより可読性を向上 |

### 2. 案内ライン (Navigation Line)
ルート表示に使用するラインの仕様です。

| 項目 | 指定値 (計算式) | 備考 |
| :--- | :--- | :--- |
| **線の太さ (strokeWidth)** | `10 / scale` | 地図上で埋もれない太さ |
| **点線間隔 (dasharray)** | `20 / scale, 20 / scale` | 動的なスケールに対応 |
| **線の色** | `#1d4ed8` (青系) | |
| **矢印 (markerEnd)** | `url(#arrowhead)` | 進行方向を示す矢印を必須とする |

### 3. 必須UI機能 (Functional Components)
削除してはいけない重要な操作要素です。

#### 目的地昇格ボタン (Promote Button)
- **表示場所**: 目的地検索ボックスの右端（`search-actions` 内）
- **形状**: `▲` (背景なし)
- **機能**: タップで目的地を現在地にコピーし、目的地をクリアする

#### お気に入りボタン (Favorites Button)
- **表示場所**: 画面右側、下から170px付近 (`fav-footer-btn`)
- **アイコン**: ★ (オレンジ背景)
- **機能**: お気に入りリストの表示、およびマップ上への一括表示切り替え

#### 案内履歴 (History Feature)
- **表示場所**: 画面右側、下から100px付近 (`history-btn`)
- **アイコン**: 時計/戻るアイコン
- **機能**: 過去20件の案内履歴を保存、個別削除、および再設定可能にする
- **並び順**: 新しいものが一番下に表示される（昇順）

#### 画面右下アクション群 (Bottom Right Actions)
- **構成**: [？（ヘルプ）] [マップ（リセット）] の横並び配置
- **表示場所**: 画面右下、下から30px付近 (`bottom-right-actions`)
- **配置順**: ヘルプが左、マップが右

#### 地図中央吹き出し (Booth Tooltip)
- **表示場所**: ズーム率 3.0倍以上で地図中央に表示
- **機能**: 照準（クロスヘア）が指しているブース名を表示し、タップで目的地に設定できる
