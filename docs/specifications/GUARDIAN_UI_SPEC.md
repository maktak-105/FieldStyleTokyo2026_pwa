# プロジェクト仕様書：Guardian 監査システムおよび UI 表示基準

## ステータス：確定（Verified）

本ドキュメントは、FieldStyle2026 プロジェクトにおけるコードの整合性維持および UI の視覚的基準を定義する。

### 1. Guardian 監査システム仕様

プロジェクトの整合性を維持するため、独立した監査システムを運用する。

* **監査スクリプト (`scripts/guardian.cjs`)**:
  * **目的**: ソースコードが README.md に定義された機能的・視覚的仕様から逸脱していないかを検証する。
  * **チェック項目**: マーカーの定数、カラーコードの整合性、検索エンジンの閾値設定など。
* **Pre-commit フック (Husky)**:
  * Git コミット時に `guardian.cjs` を自動実行する。
  * 監査に失敗したコードはコミットを拒否され、仕様への 100% の適合を物理的に強制する。

### 2. UI 表示・検索ロジック仕様

以下の値は、リファレンス画像および本番環境との 1:1 のパリティを維持するための固定値である。

* **マーカー表示仕様**:
  * **外円（Circle）**: 半径（Radius） `22 / scale`、ストローク幅 `5 / scale`
  * **テキスト**: フォントサイズ `22 / scale`、太字（Bold） `900`、枠線（stroke） `2 / scale`
  * **色**: 白色のストローク、および各カテゴリ別の塗潰し色。
* **ナビゲーションライン仕様**:
  * **線の太さ (Stroke Width)**: `10 / scale`
  * **点隔 (Dash Array)**: `20 / scale, 20 / scale`
  * **線の色**: `#1d4ed8` (青)、**透過なし (opacity: 1.0)**
* **検索ロジック (Fuse.js)**:
  * **閾値 (Threshold)**: `0.4`
  * この値は、曖昧検索の許容度を最適化し、不正確なマッチングを抑制するために厳守すること。

### 3. 操作仕様

* **Pinch-to-Zoom**:
  * モバイルおよびデスクトップ環境におけるスムーズな拡大縮小をサポートし、座標計算の整合性を維持する。
