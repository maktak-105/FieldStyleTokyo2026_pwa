# プロジェクト仕様書：Guardian 監査システムおよび UI 表示基準

## ステータス：確定（Verified）

本ドキュメントは、FieldStyle2026 プロジェクトにおけるコードの整合性維持および UI の視覚的基準を定義する。

### 1. Guardian 監査システム仕様

プロジェクトの整合性を維持するため、独立した監査システムを運用する。

* **監査スクリプト (`scripts/guardian.cjs`)**:
  * **目的**: ソースコードが README.md に定義された機能的・視覚的仕様から逸脱していないかを検証する。
  * **チェック項目**: マーカーの定数、カラーコードの整合性、検索エンジンの閾値設定など。
* **Pre-commit フック (Husky)**:
  * Git コミット時に `guardian.cjs` を自動実行する。
  * 監査に失敗したコードはコミットを拒否され、仕様への 100% の適合を物理的に強制する。

### 2. UI 表示・検索ロジック仕様

以下の値は、リファレンス画像および本番環境との 1:1 のパリティを維持するための固定値である。

* **マーカー表示仕様**:
  * **外円（Circle）**: 半径（Radius） `22 / scale`、ストローク幅 `5 / scale`
  * **テキスト**: フォントサイズ `22 / scale`、太字（Bold） `900`、枠線（stroke） `2 / scale`
  * **色**: 白色のストローク、および各カテゴリ別の塗潰し色。
* **ナビゲーションライン仕様**:
  * **線の太さ (Stroke Width)**: `10 / scale`
  * **点隔 (Dash Array)**: `20 / scale, 20 / scale`
  * **線の色**: `#1d4ed8` (青)、**透過なし (opacity: 1.0)**
* **検索ロジック (Fuse.js)**:
  * **閾値 (Threshold)**: `0.4`
  * この値は、曖昧検索の許容度を最適化し、不正確なマッチングを抑制するために厳守すること。

### 3. 操作仕様

* **Pinch-to-Zoom**:
  * モバイルおよびデスクトップ環境におけるスムーズな拡大縮小をサポートし、座標計算の整合性を維持する。

### 4. 追加詳細仕様（README V11 準拠）

#### 4.1 すべてのUI詳細

- **星型マーカー**: 半径 `24 / scale`, 枠線 `3 / scale`, 色 `#f59e0b`
* **ボタン配置**: お気に入り(`bottom: 170px`), 履歴(`bottom: 100px`), ヘルプ・マップ(`bottom: 30px`)
* **プレミアム余白**: 履歴アイテム間 `gap: 12px`, 履歴ヘッダー(左詰め) `gap: 12px`
* **照準 (クロスヘア)**: 直径 `32px`, 透過度 `0.8` (白色)
* **しきい値**: 吹き出し表示 `scale >= 1.0`
* **フィードバック**: ボタン押下時 `scale(0.92)`, グローバル `transition: 0.2s`

#### 4.2 すべての画面機能詳細

- **マップ**: 1F/4F切替, 地図リセット(全体表示)
* **検索・案内**: 1文字曖昧検索, 目的地昇格(▲), A-B間青点線案内, フロアまたぎ時のエスカレーター自動経由案内
* **履歴・並べ替え**: DndContext/SortableContext による並べ替え, DragOverlay 実装, 一括表示トグル, 履歴削除時の一括クリア(現在地・目的地・検索結果の全初期化)

#### 4.3 すべてのヘルプ内容詳細
- **使い方ガイド項目**:
    1. **マップ切替**: 上部のタブでフロアを切り替え。
    2. **検索**: ブース番号や名称で素早く検索。
    3. **ジャンプボタン**: 検索窓横のボタンで対象に移動。
    4. **お気に入り**: ☆★ボタンで登録し、★ボタンで一括表示。
    5. **ナビゲーション**: 青点線でルートを案内（エスカレータ経由）。
    6. **地図上の記号**: ● 一般 / ■ 昇降機 / ▲ 喫煙所
    7. **地図の操作**: ピンチ操作でズーム、ドラッグで移動。
    8. **地図リセット**: 右下の地図ボタンで全体を表示。
    9. **★ボタン**: お気に入り表示
- **共有機能**: QRコードボタンからアプリURLを共有可能。
- **ビジュアル確認**: 作者アイコンやQRコードをタップして拡大表示。
- **技術スタック項目**: TypeScript, React (v19), Vite (v7), Python, PWA, Fuse.js, react-quick-pinch-zoom, Lucide React, Pillow (PIL), Vercel, GitHub
