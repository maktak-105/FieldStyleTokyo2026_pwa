# プロジェクト仕様書：履歴ルート案内機能（Route Navigation History）

## ステータス：ドラフト（Draft）

本ドキュメントは、履歴画面におけるルート表示および編集機能の仕様を定義する。

### 1. ルート表示ロジック

履歴に存在するブースを順番に結び、マップ上にルートを表示する。

* **表示対象**:
  * 履歴リスト内で「チェック（有効）」が入っているすべてのマーカーおよびそれらを結ぶ矢印。
  * チェックが外されたアイテムはマップに表示されず、その前後の有効なアイテムが直接線で結ばれる。
  * **矢印の接続制限**: 
    * 全ての矢印は開始と目的地のマーカーをつなぐこと
    * マーカーにつながっていない矢印は表示させないこと
* **マーカー配色ルール**:
  * **開始地点 (Start)**: 有効な履歴のうち、最初のブースを**赤色 (#FF0000)** で表示。
  * **経由地点 (Intermediate)**: 途中にあるすべての有効なブースを**緑色 (#00FF00)** で表示。
  * **到着地点 (End)**: 有効な履歴のうち、最後のブースを**青色 (#0000FF)** で表示。
* **制約事項**:
  * **保存件数**: 制限なし。
  * **時刻表示**: 不要（実装しない）。
  * **変更を許可するのは背景色（背景の円の塗潰し）のみ**とする。

### 2. UI コンポーネント仕様

* **ヘッダーレイアウト**:
  * **[案内履歴タイトル] [すべて表示ボタン] を左詰め**に配置し、[一括削除ボタン] を右端に配置する（Flexbox gap: 16px）。
  * 要素間のバランスと垂直方向の中央揃えを最適化し、スカスカとした違和感を排除する。
  * タイポグラフィと余白を精密に調整し、プレミアムで洗練された質感を実現する。
* **すべて表示ボタン**:
  * ボタン形式：**「アイコンなし」のテキストのみ**（`すべて表示` / `一括解除`）。
  * クリックすることで、有効なルート全体のマップ表示/非表示を切り替える。
  * **初期状態は OFF（非表示）とする。**
* **削除ボタン (一括クリア)**:
  * ヘッダーの右端に配置。全履歴を即座に消去し、現在地・目的地の入力および選択状態も同時にクリアする。

* **履歴アイテム（各行）**:
  * **要素の配置順**: `[並べ替えハンドル]` - `[チェックボックス]` - `[ブース情報]` --- `[個別削除ボタン]`
  * **左端 (並べ替えハンドル)**: ドラッグアンドドロップによる順序変更用。
  * **チェックボックス (デフォルト：ON)**: ハンドルの右隣。チェックの有無がルート表示に即座に反映される。
  * **中央 (ブース情報)**: 常に **`[ブース番号] 店名`** の形式で表示。
  * **右端 (個別削除ボタン)**: 赤いマイナスアイコン。アイテムを履歴から即座に削除する。

### 3. 状態管理とリアクティビティ

* **即座な反映**:
  * 順序変更、削除、チェック状態の変更は、すべて状態（State）を通じてマップ上の SVG レンダリングに即時反映されなければならない。
* **順序の定義**:
  * リストの「上」から「下」への順番を、ルートの「開始」から「終了」として扱う。
